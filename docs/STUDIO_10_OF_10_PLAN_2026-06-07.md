## What's intentionally OUT OF SCOPE (deferred)

- **Generative video from text** (Sora, Runway, Pika) — would need separate agent + expensive API; revisit post-10/10
- **Real-time collaborative editing** (multi-user on same project) — complex; defer
- **Mobile app** — web is the priority
- **Voice input** (Whisper-streaming) — TTS yes, STT no
- **Custom LUTs / user uploads** — defer to v2

## Definition of Done for "10/10"

A new user with no prior context should be able to:
1. Sign up via OAuth
2. Paste a YouTube URL → ingest
3. Type "make me a 60-sec TikTok from this, remove silence, add captions, add upbeat music, post to my TikTok"
4. Get a real file on their TikTok within 5 minutes
5. See the whole flow in their conversation history with an audit trail

If all 4 phases ship and all DoD items pass, that's 10/10.
