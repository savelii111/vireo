# Vireo Studio Desktop Shell — W21

This folder adds the Electron desktop wrapper for Vireo Studio.

## Runtime model

- Main process: `desktop/main.js`
- Renderer: existing Vite app at `frontend/`
- Preload bridge: `desktop/preload.js`
- Custom protocol: `vireo://`
- Backend API: `http://localhost:3000` in dev, configurable via `VIREO_API_BASE_URL`

## Commands

From `agents/studio`:

```bash
npm run desktop:dev
npm run desktop:build
npm run desktop:package
npm run desktop:package:win
npm run desktop:package:mac
npm run desktop:package:linux
```

## Security defaults

- `nodeIntegration: false`
- `contextIsolation: true`
- `sandbox: true`
- explicit IPC allowlist
- CSP with `object-src 'none'`, `base-uri 'none'`, and `frame-ancestors 'none'`
- external URL allowlist for docs/help/video links

## Packaging

Packaging config is generated by `DesktopPackager` and mirrored in `package.json` scripts. Electron/Electron Builder are declared as dev dependencies so the desktop build path is explicit instead of hidden.
